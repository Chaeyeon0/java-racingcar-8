# java-racingcar-precourse

### 🚀 미션 개요

간단한 자동차 경주 게임을 구현한다.

사용자가 입력한 자동차 이름과 시도 횟수에 따라 자동차들이 전진하거나 멈추며, 최종 우승자를 계산하여 출력하는 프로그램이다.

---

## 🗂️ 패키지 구조

```
java-racingcar
 ├── Application.java                // 진입점
 │
 ├── controller
 │   └── GameController.java         // 전체 흐름 제어
 │
 ├── domain
 │   ├── Car.java                    // 자동차 (이름 + 이동 거리 + 전진 로직)
 │   ├── Cars.java                   // 자동차 전체 이동, 우승자 판별)
 │   ├── MovementStrategy.java       // 전진 조건 인터페이스
 │   └── RandomMovementStrategy.java // 랜덤 이동 전략 구현체
 │
 └── view
     ├── InputView.java              // 입력 담당
     └── OutputView.java             // 출력 담당
```

## 🧩 기능 요구사항

### 1️⃣ 자동차 기본 동작

- 자동차는 이름과 이동 거리를 가진다.
- 이름은 5자 이하만 가능하며, 초과 시 `IllegalArgumentException`을 발생시킨다.
- 자동차는 0~9 사이의 무작위 수를 뽑고, 4 이상일 경우 전진, 그렇지 않으면 멈춘다.
- [x]  자동차 생성 시 이름 길이 검증
- [x]  이동 조건(랜덤 값 ≥ 4일 때 전진) 구현
- [x]  이동 거리 상태값 업데이트
- [x]  자동차 이름 및 상태 반환 메서드 구현

---

### 2️⃣ 자동차 그룹 관리 (Cars)

- 여러 대의 자동차를 관리하는 역할이다.
- 전체 자동차를 한 번에 전진시키고, 우승자를 판단한다.
- [x]  자동차 리스트를 생성 및 보유
- [x]  모든 자동차 전진 기능 구현
- [x]  각 자동차의 현재 거리 출력 기능
- [x]  최종 우승자(복수 가능) 계산 기능

---

### 3️⃣ 이동 전략

- 자동차의 전진 여부를 판단하는 전략 패턴을 적용.
- 기본 구현은 랜덤 숫자 생성 로직을 사용한다.
- [x]  `MovementStrategy` 인터페이스 정의
- [x]  `RandomMovementStrategy` 클래스 구현

---

### 4️⃣ 입력 / 출력

### `InputView`

- 사용자로부터 자동차 이름과 시도 횟수를 입력 받는다.
- 쉼표(`,`)를 기준으로 이름을 구분한다.
- 잘못된 입력(5자 초과 이름, 비정상 횟수 등) 시 `IllegalArgumentException` 발생.

### `OutputView`

- 각 라운드별 실행 결과 및 최종 우승자를 출력한다.
- [x]  경주할 자동차 이름 입력받기
- [x]  시도 횟수 입력받기
- [x]  각 라운드별 결과 출력
- [x]  최종 우승자 출력

---

- 입력 → 비즈니스 로직 실행 → 결과 출력까지의 과정 담당.

- [x]  각 라운드 결과 출력 (`OutputView`)
- [x]  최종 우승자 출력 (`OutputView`)

## 추가 고려사항

- **자동차는 후진하지 않는다.**
  - 자동차 경주는 “뒤로 가는 행위”를 포함하지 않는다!
  - 이동 조건이 만족되지 않으면 현재 위치에 머무른다.

- **자동차의 이동은 각 라운드마다 독립적으로 판단된다.**
  - 한 번의 시도(`moveAll()`)에서 자동차는 무작위 값(0~9)에 따라 `distance`가 +1 되거나 그대로 유지된다
  - 한 번 이동한 자동차도 다음 턴에 이동 조건이 불충족되면 멈춘다
  - 매 턴마다 확률적으로 이동 여부를 재평가하는 구조로 설계한다
